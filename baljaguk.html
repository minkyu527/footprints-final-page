01 — 프로젝트 개요

무엇을 만드는가

데이터는 쌓이고, 관계는 희미해진다. 발자국은 잊혀진 인연을 데이터로 되살리는 자동화 에이전트다.

서비스 정의
관계를 추적하는 에이전트
캘린더, GPS, 카카오톡 데이터를 교차 검증해 실제 만남과 연락을 자동으로 기록. 사용자가 인식하지 못하는 사이, 관계의 밀도를 측정한다.
타겟 사용자
김민규 (나)
바쁜 일상 속에 누군가와 오래 연락 안 했다는 사실을 뒤늦게 깨닫는 사람. 관계에 마음은 있지만, 먼저 연락하는 걸 자꾸 미루는 사람.
핵심 가치 — 3가지
연락의 소홀함을 방지하는 자동화된 관계 추적. 사용자가 아무것도 하지 않아도, 만남과 연락이 자동으로 기록된다.
사용자 입력 최소화 (Zero-UI 지향). 직접 입력 없이도 데이터가 생성된다. UI는 브리핑과 알림에만 쓰인다.
데이터 기반의 객관적인 관계 브리핑. 감정이 아니라 숫자로, 관계의 현재 상태를 직시할 수 있다.
02 — 핵심 기능

어떻게 작동하는가

4개의 데이터 소스를 실시간으로 교차 검증해 하나의 '만남 발자국'을 생성한다.

📅
Google Calendar API
식사, 저녁, 미팅, 이름 등 특정 키워드가 포함된 일정을 자동 추출해 만남 후보를 수집한다.
만남 후보 수집
📍
Expo GPS 교차검증
Expo 앱으로 상시 위치를 기록. 캘린더 일정의 장소와 실제 체류 여부를 교차 검증해 진짜 만남만 남긴다.
위치 체류 검증
👣
FootPrints Logic
캘린더 + GPS 두 데이터가 일치할 때 비로소 하나의 '만남 발자국'으로 자동 생성된다.
핵심 로직
💬
카카오톡 자동 크롤링
카카오톡 대화 목록을 수집, 연락 빈도와 안 읽음 수를 분석해 연락 점수를 산출한다.
연락 빈도 추출
🌤
날씨 데이터 연동
날씨가 좋고 일정이 없는 날짜를 추천. 소홀한 관계에게 연락하기 딱 좋은 날을 알려준다.
날짜 추천
⭐
관계 별자리
만남 빈도와 연락 빈도를 합산한 친밀도 점수로, 나를 중심에 둔 인간관계 네트워크를 시각화한다.
최종 아웃풋
03 — 친밀도 점수

관계를 어떻게 계산하는가

주관을 배제하고, 데이터로만 관계의 밀도를 측정하는 공식.

Intimacy Score Formula
intimacyScore =
  ( 만남 점수 × 0.5 ) +
  ( 연락 점수 × 0.5 )
연락 점수 =
  recencyScore(마지막 연락일) × 0.6
  + 안읽음수 기반 × 0.4
만남 점수 50%
캘린더 + GPS 교차 검증된 실제 만남 빈도
최근성 점수 (recency) 30%
마지막 연락일 기준 감쇠 함수 적용
안읽음 기반 점수 20%
카카오톡 안읽음 수로 연락 빈도 보정
